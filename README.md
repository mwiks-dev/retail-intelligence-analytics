# Retail Intelligence Analytics

An end-to-end analytics project focused on retail merchandising,
pricing, supplier sourcing, inventory and profitability.

## Business Objective
Identify opportunities to improve profitability, pricing,
supplier decisions and inventory management.

## Tools
- Python
- PostgreSQL
- DBeaver
- Excel
- Power BI
- Git and GitHub

## Project Workflow
1. Data audit
2. Data cleaning and ETL
3. Relational database design
4. SQL analysis
5. Excel commercial analysis
6. Python analytics
7. Power BI reporting
8. Executive recommendations

## Dataset
Global E-Commerce & Supply Chain Database (Kaggle).

## Status
Environment setup and initial data audit.
